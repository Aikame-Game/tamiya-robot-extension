# 🤖 タミヤ クローラーロボット プログラミング＆コントローラー

micro:bit を使ってタミヤのクローラーロボットを WebUSB 経由で操作できる **Scratch 3.0 カスタム拡張機能** および **WebコントローラーUI** です。

本物の Scratch (TurboWarp / Xcratch) 画面からブロックでプログラミングしてロボットを動かすことも、ブラウザ上のコントローラーや送信機 micro:bit のボタン操作で直接ラジコン操作することも可能です。

---

## 🚀 すぐに使う（Webアプリ）

- **🧩 Scratchでプログラミングする（TurboWarp）**  
  [👉 Scratchエディタを開く](https://turbowarp.org/editor?extension=https://Aikame-Game.github.io/tamiya-robot-extension/tamiya_robot_extension.js)  
  ※URLを開くだけで「タミヤロボット」専用拡張ブロックが自動で読み込まれます。

- **🎮 コントローラーで手動操作する**  
  [👉 Webコントローラーを開く](https://Aikame-Game.github.io/tamiya-robot-extension/)

## 📦 micro:bit へのプログラム書き込み手順

ロボットを動かすには、**送信機用**と**受信機用**の2台の micro:bit にプログラム（HEXファイル）を書き込む必要があります。

### 1. HEXファイルのダウンロード
本リポジトリに配置されている HEX ファイルをパソコンにダウンロードします。

- **送信機用（PC接続・単体操縦用）**: `microbit-タミヤロボット-コントローラー、送信機-独自プログラム-※microbitV2推奨.hex`
- **受信機用（ロボット搭載用）**: `rmicrobit-microbitタミヤロボット-走行用プログラム-独自プログラム-※V1マイクロビット推奨.hex`

### 2. 書き込み方法（ドラッグ＆ドロップ）
1. パソコンに **送信機用 micro:bit** を USB ケーブルで接続します。
2. パソコンに「`MICROBIT`」という名前のドライブ（USBメモリのように）が表示されます。
3. ダウンロードした **送信機用 HEX ファイル** を `MICROBIT` ドライブへドラッグ＆ドロップ（コピー）します。
4. micro:bit 背面の裏側のLEDが点滅し、点滅が終われば書き込み完了です。
5. **受信機用 micro:bit** も同様にパソコンに接続し、**受信機用 HEX ファイル** を書き込んでからロボットに搭載してください。

## 🎮 送信機 micro:bit 単体での操縦方法

パソコンやスマホを使わず、**送信機用 micro:bit の本体ボタン操作（または傾き操作）**だけでロボットを操縦することも可能です。

| 操作方法 | 動作コマンド | ロボットの挙動 |
| :--- | :---: | :--- |
| **Aボタンを押す** | `F` | **前進**（ギア1 / 標準速度） |
| **Bボタンを押す** | `B` | **バック**（ギア1 / 標準速度） |
| **A+Bボタンを同時に押す** | `S` | **停止** |
| **micro:bit を左に傾ける** | `L` | **左旋回** |
| **micro:bit を右に傾ける** | `R` | **右旋回** |
| **ロゴにタッチ（V2の場合）** | `H` | **クラクションを鳴らす** |

## ✨ 主な機能

### 1. Scratch 3.0 拡張機能 (`tamiya_robot_extension.js`)
- **コマンド送信**: 前進（ギア1/2）、バック（ギア1/2）、左右旋回、停止、クラクション
- **イベント検知（ハットブロック）**: ロボット側の「壁接近（`WALL`）」「転倒（`FLIP`）」警報信号をリアルタイム受信してプログラムを割り込み表示

### 2. Webコントローラー (`index.html`)
- **2段階矢印ボタン**: ワンタップで1速（標準）/ 2速（高速）を直感的に切り替え
- **安全停止機能**: 「STOP」ボタンや別ボタンタップで安全に動作切替
- **警報ポップアップ表示**: ロボットの壁接近や転倒通知を画面上に視覚的アラート表示
- **Scratch連携ボタン**: ワンタップでScratchエディタへジャンプ

## 🔧 動作環境・要件

### 動作対応ブラウザ
- **Google Chrome**（推奨）
- **Microsoft Edge**
- **Opera**  
※ **Safari** および **Firefox** は Web Serial API 非対応のため動作しません。

### 必要なハードウェア
1. **パソコン / Chromebook**（USBポート搭載、またはOTG対応Android）
2. **micro:bit** × 2台（送信機用: V2推奨 / 受信機用: V1推奨）
3. **USB ケーブル**
4. **タミヤ クローラーロボット**（受信用 micro:bit とモータードライバー等を搭載）

## 📡 通信プロトコル仕様

WebUSB (115200 bps) で送信機 micro:bit へ送信される文字列コマンド一覧：

| コマンド | 動作 |
| :---: | :--- |
| `F` | 前進（ギア1 / 標準速度） |
| `F2` | 前進（ギア2 / 高速） |
| `B` | バック（ギア1 / 標準速度） |
| `B2` | バック（ギア2 / 高速） |
| `L` | 左旋回 |
| `R` | 右旋回 |
| `S` | 停止 |
| `H` | クラクション |
| `WALL` | （受信）壁接近アラート |
| `FLIP` | （受信）転倒アラート |
